# 故障机器人和地精大块头
## 用Godot做的简单小游戏
### 支持Windows
### 游戏玩法
- 点击SPACE进入游戏
- 鼠标点击发射子弹
- WSAD控制方向
- 拾取能量球，能量满时，点击E释放大招
